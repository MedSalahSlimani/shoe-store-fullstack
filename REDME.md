# 👟 Shoe Store - Application Fullstack

## 📖 Description
Application complète de gestion de vente de chaussures avec :
- **Backend** : Spring Boot (API REST, JWT, JPA, MySQL)
- **Frontend** : Angular 17+ (standalone components)
- **IA** : Ollama avec modèle Gemma 2:2b (chatbot assistant)

## 🚀 Fonctionnalités

### Backend (Spring Boot)
- ✅ Authentification JWT (login/register)
- ✅ Gestion des rôles (ADMIN / USER)
- ✅ CRUD chaussures
- ✅ API REST complète
- ✅ Chat IA avec Ollama

### Frontend (Angular)
- ✅ Interface responsive
- ✅ Connexion / Inscription
- ✅ Liste des chaussures
- ✅ Ajouter, modifier, supprimer
- ✅ Recherche par marque/modèle/taille
- ✅ Dashboard statistiques
- ✅ Assistant IA (chat avec Gemma 2:2b)

## 🛠️ Technologies

| Backend | Frontend |
|---------|----------|
| Spring Boot 3.2.0 | Angular 17+ |
| Spring Security | TypeScript |
| JWT | Bootstrap 5 |
| Spring Data JPA | Chart.js |
| MySQL | HttpClient |
| Ollama (Gemma 2:2b) | - |

## 📦 Prérequis

- Java 17+
- MySQL (XAMPP)
- Node.js 18+
- Angular CLI
- Ollama (avec gemma2:2b)
